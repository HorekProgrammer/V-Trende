# robots.txt and sitemap.xml deployment

Vite copies `frontend/public/robots.txt` to `frontend/dist/robots.txt`. With the
usual SPA fallback, `try_files $uri $uri/ /index.html`, Nginx serves this real
file before falling back to React.

The sitemap is generated by FastAPI from published ranking data. Add these exact
locations to the HTTPS `server` block for `vcharte.com` and replace the old
`try_files ... /index.html` SPA fallback with the routes below.
The explicit `robots.txt` location prevents a missing file from falling through
to `index.html`:

```nginx
location = /robots.txt {
    try_files /robots.txt =404;
    default_type text/plain;
}

location = /sitemap.xml {
    proxy_pass http://127.0.0.1:8765/sitemap.xml;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}

# The home page is rendered with the current rankings by FastAPI. The response
# is identical for users and crawlers; React takes over after loading.
location = / {
    proxy_pass http://127.0.0.1:8765/web/home;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}

location ^~ /assets/ {
    try_files $uri =404;
}

location = /icon.png {
    try_files /icon.png =404;
}

location ~ ^/category/([^/]+)$ {
    proxy_pass http://127.0.0.1:8765/web/category/$1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}

location ~ ^/category/([^/]+)/$ {
    return 301 /category/$1;
}

location ~ ^/trend/([0-9]+)$ {
    proxy_pass http://127.0.0.1:8765/web/trend/$1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}

location ~ ^/trend/([0-9]+)/$ {
    return 301 /trend/$1;
}

# Do not turn unknown paths into successful copies of index.html.
location / {
    return 404;
}
```

Then validate and reload Nginx:

```bash
sudo nginx -t
sudo systemctl reload nginx
```

Verification:

```bash
curl -i https://vcharte.com/robots.txt
curl -i https://vcharte.com/sitemap.xml
curl -i https://vcharte.com/category/music
```
